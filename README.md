## About

I'm **SuBZeRo**, a physician and independent Android developer based in **Tamil Nadu, India**.

I approach software with a practical mindset: understand the real workflow, identify the problem worth solving, and build a focused tool people can rely on. My current work centres on native Android applications using **Kotlin**, **Jetpack Compose**, and modern Android development practices.

- Building native Android applications and product experiences.
- Creating tools for retail, pharmacy, inventory, personal finance, and clinic workflows.
- Applying layered architecture, reactive UI state, local persistence, and automated tests.
- Prioritising accurate calculations, maintainable code, and clear documentation.
- Favouring privacy-conscious products with transparent, user-controlled behaviour.

> Useful features. Dependable engineering. No unnecessary complexity.

## Principles

<details><summary><strong>01 | Solve a real problem</strong></summary><br/>Understand the user, workflow, constraints, and expected outcome before adding features.</details>
<details><summary><strong>02 | Keep architecture maintainable</strong></summary><br/>Separate UI, business logic, and data responsibilities. Prefer clear state flows and small, testable components.</details>
<details><summary><strong>03 | Treat correctness as a feature</strong></summary><br/>Validate calculations, boundary conditions, persistence, and database migrations. Make quality claims only when supported by evidence.</details>
<details><summary><strong>04 | Respect user privacy</strong></summary><br/>Prefer on-device processing and transparent network behaviour. Avoid accounts, advertising, analytics, and unnecessary data collection.</details>
<details><summary><strong>05 | Ship thoughtfully</strong></summary><br/>Keep documentation current, version releases clearly, and make installation and support information easy to find.</details>
